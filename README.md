# System Resource Monitor

A Python project that monitors system resources on Linux.

## Features
- Monitor CPU usage
- Monitor RAM usage
- Monitor disk usage
- Display warnings when usage exceeds thresholds
- Record system information in log files
- Automated tests using pytest
- Continuous Integration using GitHub Actions

## Requirements
- Python 3
- psutil
- pytest

## Run the project

Activate the virtual environment:

source .venv/bin/activate
